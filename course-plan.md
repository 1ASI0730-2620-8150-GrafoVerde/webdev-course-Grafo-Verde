# Fundamentos de Desarrollo Web

## Resumen del Curso

Curso introductorio de aproximadamente 1 hora dirigido a estudiantes
de secundaria sin experiencia previa en programación.

## Secuencia de Lecciones

### Lección 1: ¿Qué es el desarrollo web?

**Descripción:**  
Introducción a los conceptos fundamentales del desarrollo web.
El estudiante conocerá qué es una página web y comprenderá el propósito
general de HTML y CSS. Todo el video transcurre en CodePen: se ve la misma
página primero solo con HTML y luego con CSS, se construye el proyecto
del curso paso a paso y se hace una primera prueba cambiando un título y su color.

**Objetivos de aprendizaje:**

- Comprender qué es una página web.
- Reconocer HTML como responsable del contenido y estructura.
- Reconocer CSS como responsable de la apariencia.
- Diferenciar entre contenido y apariencia.
- Conocer el proyecto que se desarrollará durante el curso.

**Conceptos clave:**

- Desarrollo web.
- Página web.
- Navegador web.
- HTML.
- CSS.
- Contenido, estructura y apariencia.

### Lección 2: Introducción a HTML

**Descripción:**  
Introducción a la estructura de una página web con HTML.
El estudiante conocerá qué son las etiquetas, los elementos y los atributos,
y construirá la estructura básica de una página.

**Objetivos de aprendizaje:**

- Identificar etiquetas de apertura y de cierre.
- Diferenciar etiqueta, contenido y elemento.
- Escribir atributos con su nombre y su valor.
- Construir la estructura básica de una página web.
- Reconocer los errores más comunes al empezar.

**Conceptos clave:**

- Etiqueta.
- Elemento.
- Atributo.
- Estructura de una página.
- Indentación.

### Lección 3: Elementos HTML comunes

**Descripción:**  
Uso de los elementos que dan contenido a una página web.
El estudiante aprenderá a usar encabezados, párrafos, imágenes, listas
y enlaces mientras construye una página de ejemplo.

**Objetivos de aprendizaje:**

- Usar encabezados según su lugar en el contenido.
- Escribir párrafos y marcar texto importante.
- Agregar imágenes con los atributos `src` y `alt`.
- Diferenciar listas sin orden y listas ordenadas.
- Crear enlaces con texto descriptivo.

**Conceptos clave:**

- Encabezados.
- Párrafos.
- Imágenes.
- Listas.
- Enlaces.

### Lección 4: Introducción a CSS y estilo simple

**Descripción:**  
Primeros pasos para dar estilo a una página con CSS.
El estudiante aprenderá a elegir qué elemento quiere cambiar con un selector de etiqueta
o de clase, y a cambiar colores, agregar bordes, centrar contenido y convertir un enlace
en un botón mientras transforma una página sencilla sin tocar su HTML.

**Objetivos de aprendizaje:**

- Seleccionar elementos por su etiqueta (`body`, `h1`, `p`, `a`) y por su clase (`.card`).
- Cambiar el color de fondo de una página.
- Cambiar el color del texto.
- Centrar contenido utilizando CSS sencillo.
- Agregar bordes a un elemento.
- Aplicar esquinas redondeadas.
- Combinar varias propiedades CSS para mejorar visualmente una página web.

**Conceptos clave:**

- Selectores de etiqueta y selectores de clase.
- `background-color` y `color`.
- `padding`.
- `border` y `border-radius`.
- `max-width` y `margin`.
- `text-align`.
- `text-decoration`.

**Video:**  
[Ver Lección 4 en YouTube](https://www.youtube.com/watch?v=6yxLbDr2KYE)

**Práctica:**  
[Abrir ejemplo en CodePen](https://codepen.io/editor/darnell1910/pen/01a1b389-0aba-7fd8-9bbb-a0085db45175)

**Código fuente:**

- [Starter Files](starter-files/lesson-04)
- [Completed Example](completed-examples/lesson-04)

**Consejo clave:**  
`margin: auto` centra la tarjeta y `text-align: center` centra el contenido que está dentro de ella.

**Si un estilo no aparece, revisa:**

- Que el selector coincida con la etiqueta o la clase del HTML.
- Que el nombre de la clase lleve un punto en el CSS (`.card`), pero no en el HTML (`class="card"`).
- Que la propiedad esté bien escrita (`color`, no `colour`).
- Que cada propiedad termine en `;` y cada regla tenga sus llaves `{ }`.
- Que los valores lleven unidad cuando la necesitan (`16px`, no `16`).

**Para seguir aprendiendo:**

- [Guía de CSS en MDN Web Docs](https://developer.mozilla.org/es/docs/Web/CSS)
- [Validador de CSS del W3C](https://jigsaw.w3.org/css-validator/)

### Lección 5: Creación de una página web

**Descripción:**  
El estudiante aplicará lo aprendido en las lecciones anteriores para crear una página web completa.
Se utilizarán HTML y CSS para construir una página con contenido, estilo y estructura, consolidando los conocimientos adquiridos.
Agregaremos un encabezado, párrafos, secciones y divisiones y aplicaremos estilos para mejorar la apariencia de la página.

**Objetivos de aprendizaje:**

- Crear una pagina web sobre un perfil de internet como ingeniero de software, diseñador web o desarrollador de videojuegos.
- Agregar una estructura en lista de cartas dentro de una sección.
- Combinar varias propiedades CSS para mejorar visualmente una página web.

**Conceptos clave:**

- `div` y `section`.
- `padding`.
- `background-color`
- `border` y `border-radius`.
- `max-width` y `margin`.
- `text-align`.

✅ Lista de revisión cuando algo no funciona:
1. ¿Qué fue lo último que cambié? (Ctrl/Cmd + Z para deshacer)
2. ¿Cerré todas las etiquetas?
3. ¿Escribí bien los atributos y las propiedades?
4. ¿Puse el punto antes del nombre de la clase?
5. ¿Cada propiedad termina con ; y cada regla con } ?
**Conclusiones clave**: Escribe un codigo ordenado, deja notas con comentarios, usar nombres claros y el habito de cazar errores.
