# Fundamentos de Desarrollo Web

## Resumen del Curso

Curso introductorio de aproximadamente 1 hora dirigido a estudiantes
de secundaria sin experiencia previa en programación.

## Secuencia de Lecciones

### Lección 1: ¿Qué es el desarrollo web?

**Descripción:**  
Introducción a los conceptos fundamentales del desarrollo web.
El estudiante conocerá qué es una página web y comprenderá el propósito
general de HTML y CSS. Todo el video transcurre en CodePen: se ve la misma
página primero solo con HTML y luego con CSS, se construye el proyecto
del curso paso a paso y se hace una primera prueba cambiando un título y su color.

**Objetivos de aprendizaje:**

- Comprender qué es una página web.
- Reconocer HTML como responsable del contenido y estructura.
- Reconocer CSS como responsable de la apariencia.
- Diferenciar entre contenido y apariencia.
- Conocer el proyecto que se desarrollará durante el curso.

**Conceptos clave:**

- Desarrollo web.
- Página web.
- Navegador web.
- HTML.
- CSS.
- Contenido, estructura y apariencia.

### Lección 2: Introducción a HTML

**Descripción:**  
Introducción a la estructura de una página web con HTML.
El estudiante conocerá qué son las etiquetas, los elementos y los atributos,
y construirá la estructura básica de una página.

**Objetivos de aprendizaje:**

- Identificar etiquetas de apertura y de cierre.
- Diferenciar etiqueta, contenido y elemento.
- Escribir atributos con su nombre y su valor.
- Construir la estructura básica de una página web.
- Reconocer los errores más comunes al empezar.

**Conceptos clave:**

- Etiqueta.
- Elemento.
- Atributo.
- Estructura de una página.
- Indentación.

### Lección 3: Elementos HTML comunes

**Descripción:**  
Uso de los elementos que dan contenido a una página web.
El estudiante aprenderá a usar encabezados, párrafos, imágenes, listas
y enlaces mientras construye una página de ejemplo.

**Objetivos de aprendizaje:**

- Usar encabezados según su lugar en el contenido.
- Escribir párrafos y marcar texto importante.
- Agregar imágenes con los atributos `src` y `alt`.
- Diferenciar listas sin orden y listas ordenadas.
- Crear enlaces con texto descriptivo.

**Conceptos clave:**

- Encabezados.
- Párrafos.
- Imágenes.
- Listas.
- Enlaces.

**Video:**  
[Ver Lección 3 en YouTube](https://youtu.be/FOuquPpwmRQ)

**Práctica:**  
[Abrir ejemplo en CodePen](https://codepen.io/JhosBy2005/pen/vExvaqa)

**Código fuente:**

- [Starter Files](starter-files/lesson-03)
- [Completed Example](completed-examples/lesson-03)

**Consejo clave:**  
Cada elemento cumple una función: un encabezado se elige por su lugar en el contenido, no por su tamaño.

### Lección 4: Estilo simple con CSS

**Descripción:**  
Primeros pasos para dar estilo a una página con CSS.
El estudiante aprenderá a cambiar colores, agregar bordes, centrar contenido
y convertir un enlace en un botón mientras transforma una página sencilla.

**Objetivos de aprendizaje:**

- Cambiar el color de fondo de una página.
- Cambiar el color del texto.
- Centrar contenido utilizando CSS sencillo.
- Agregar bordes a un elemento.
- Aplicar esquinas redondeadas.
- Combinar varias propiedades CSS para mejorar visualmente una página web.

**Conceptos clave:**

- `background-color` y `color`.
- `padding`.
- `border` y `border-radius`.
- `max-width` y `margin`.
- `text-align`.

**Consejo clave:**
